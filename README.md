# 出席率マネージャー 2026（3年）

時間割（`2026時間割_ver3_10.xlsx`）をもとに、科目ごとの出席率と「あと何回休めるか」を管理するWebアプリです。
サーバー不要の静的サイトなので、そのまま GitHub Pages で動きます。

## ルール（初期設定）

- 出席率 **80%未満は不可**（ちょうど80%はOK）
- **欠席1回（1授業）で2コマ減る**
- 出席率 ＝（年間の総コマ数 − 欠席で減ったコマ数）÷ 年間の総コマ数
  - 総コマ数は時間割下部の「時間」の値（＝回数×2）

| 科目 | 回数 | 総コマ | 休める回数 |
|---|---|---|---|
| プロジェクトマネジメント | 30 | 60 | 6 |
| ITゼミナール | 135 | 270 | 27 |
| 課題設定・予備調査 | 45 | 90 | 9 |
| パーソナルスキルⅤ | 15 | 30 | 3 |
| 卒業制作 | 210 | 420 | 42 |
| パーソナルスキルⅥ | 15 | 30 | 3 |

割合・減るコマ数は、アプリの「設定」タブで変更できます。

## GitHub で動かす手順

1. GitHub で新しいリポジトリを作る（例：`attendance-manager`）
2. このフォルダの中身をすべてリポジトリにアップロードする（`.nojekyll` も含める）
3. リポジトリの **Settings → Pages** を開く
4. **Source: Deploy from a branch**、**Branch: main / (root)** を選んで Save
5. 1〜2分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

## 使い方

- **出欠を記録**：週ごとに、コマごとの「出席 / 欠席 / 公欠」を押す。もう一度押すと取り消し。
  - 公欠は欠席に数えず、出席率の計算からも除きます。
- **科目ごと**：残り休める回数、現在の出席率、年間見込み、休める枠（□）を表示。
  - 緑＝安全 / 黄＝あと1回 or 0回（危険）/ 赤＝80%を下回っている
- 記録は**ブラウザ（localStorage）に保存**されます。端末が変わると引き継がれないので、設定タブの「バックアップを保存」を使ってください。

## 時間割を差し替えるとき

```bash
pip install openpyxl
python tools/build_schedule.py 新しい時間割.xlsx
```

`schedule.js` が再生成されます。コミットして push すれば反映されます。
（Excelのレイアウトが変わった場合は `tools/build_schedule.py` の列・行位置を調整してください）

## ファイル構成

```
index.html            画面
style.css             デザイン
app.js                出席率の計算と画面ロジック
schedule.js           時間割データ（自動生成）
tools/build_schedule.py   Excel → schedule.js 変換
```
