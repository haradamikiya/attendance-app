# 筋トレ記録

スマホで日々の筋トレを記録できる、インストール不要のWebアプリ（PWA）です。
サーバーもビルドも不要で、静的ファイルだけで動きます。

## できること

- 腕立て伏せ・腹筋・プランク・スクワットの4種目を、セットごとに記録（プランクは秒、ほかは回数）
- 画面最上部に **連続日数** と最長記録、直近7日の達成状況を表示
- 前回のセットを自動で入力（確認してチェックするだけ）
- セットにチェックを付けると休憩タイマーが始まる
- プランクは「タイマーで計る」で計測できる（5秒の準備カウント後に計測開始、「やめる」を押すと秒数が自動で入ってチェックされる）
- 前回までの最高を超えると「自己ベスト更新」を表示
- 月間カレンダーと、種目ごとの推移グラフ（1日の合計 / 1セットの最高）
- ほかの種目（背筋など）を自分で追加することも可能
- JSONでバックアップの書き出し・読み込み
- ホーム画面に追加すると全画面・オフラインで使える

連続日数は「1日に1セット以上チェックを付けた日」が続いた日数です。今日まだ記録していなくても、昨日まで続いていれば連続は途切れません。

記録データは **端末のブラウザ内（localStorage）だけ** に保存されます。サーバーには送信されません。

## GitHub Pagesで公開する

```bash
cd muscle-log
git init
git add .
git commit -m "筋トレ記録アプリを追加"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
git push -u origin main
```

1. GitHubのリポジトリで **Settings → Pages** を開く
2. **Source** を `Deploy from a branch`、Branch を `main` / `/ (root)` にして Save
3. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

## スマホで使う

- iPhone: Safariで上のURLを開く → 共有ボタン →「ホーム画面に追加」
- Android: Chromeで開く → メニュー →「アプリをインストール」

ホーム画面から開いて使うのがおすすめです（ブラウザのタブで使うより、データが消えにくくなります）。

## 更新するとき

`index.html` などを変更したら、`sw.js` の `CACHE` のバージョンを上げてください（`muscle-log-v4` → `v5`）。
スマホには次回起動時に反映されます。

## データについて

- 端末を替えるときや、ブラウザのデータを消すときは、設定の「データを書き出す」でバックアップしてください。
- リポジトリを公開しても、記録データは公開されません（各自の端末内にあるため）。
- アイコンを作り直したい場合は `python3 make_icons.py`（Pillowが必要）。
